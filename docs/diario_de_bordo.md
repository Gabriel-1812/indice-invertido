Regra de uso: IA usada para estudar conceitos, tirar dúvidas, realizar planos e testes.
IA nunca usada para fornecer código.


## 01. Entendimento e planejamento do projeto
- **Solicitação para IA:** Organização do projeto, conteúdo de cada entrega, definição de tempo por etapa.
- **Atividade humana:** Comparei ponto a ponto com a atividade proposta. Ao longo do desenvolvimento do projeto faço alterações no plano para retratar o que eu fiz em cada etapa, deixando só o que achei importante. 
- **Arquivo de planejamento:** docs\planejamento-indice-invertido.md

## 02. Interação de conteúdo dos arquivos e caminhos
- **Solicitação para IA:** Explicação de funções que interage com o conteúdo de outro arquivo, expressões de letras (\w)
- **Atividade humana:** Desenvolvimento do código e teste das funções

## 03. Medição de desempenho
- **Solicitação para IA:** Explicação de como fazer testes e medir desempenhos, além de como já salvar em outro arquivo os resultados feitos por teste
- **Atividade humana:** Desenvolvimento e execução dos testes.

## 04. Verificação de entrega e construção do README
- **Solicitação para IA:** Verificação da entrega do projeto, análise de cada ponto proposto e sugestão de melhorias pontuais. Além da ajuda para construção do README
- **Atividade humana:**  Alinhei ponto a ponto com o comando passado pelo professor, fiz melhorias pontuais sueridas e fiz as modificações importantes no README.
